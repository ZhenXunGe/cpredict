## 已落实的工程工作

- 保留 33 个钱包依赖的自定义许可原文；新增的 `jsonify` 公共领域声明单独保留，未改填为 MIT。
- 4 个声明补丁仅涉及 TypeScript 声明，运行 JavaScript 的内容摘要不变。无钱包 SDK 运行逻辑修改。
- 用户站构建生成 `/third-party/index.html`，显示 ConsenSys 和 Reown 声明，附随包许可副本及原始摘要。帮助页和未开放入口均可访问。
- `scripts/public-site/package-notices.mjs` 从本机实际安装的生产依赖及补充证据生成副本，跳过未安装的可选平台包，保留未知声明。网页 tree shaking 后不一定包含全部列出的包；该清单不等于浏览器实际执行清单。
- 当前本机生成包含 740 个依赖记录。最初 29 条没有独立许可副本；根据官方 npm 发布的 gitHead 补入 Safe apps SDK/provider 和 Lit SSR shim 的 3 份固定源码许可，版本/integrity/来源/正文摘要均已记录。其余 26 条仍缺独立副本，部分标准声明只出现在包元数据中。逐包名称和声明保存在构建的 `third-party/inventory.json`，未自动生成版权归属或假装已补齐。
- Node 服务镜像所携带的 `node_modules` 仍保留随包许可；不能因为某个钱包模块未被服务调用就忽略镜像内实际分发的文件。
