# Cpredict V1 manual attack-surface review

Review date: 2026-08-08. Scope: the current local, uncommitted candidate. This is an internal
manual review and does not replace either independent external audit required before mainnet.

## Review method

The review followed the Trail of Bits secure-workflow sequence used for this delivery:

1. fresh Slither analysis and explicit finding triage;
2. payment-token, Permit2 and ERC-1155 integration review;
3. inheritance, function/state-write and authorization diagrams;
4. property, invariant and boundary-test review;
5. manual inspection of trust, ordering, signature, clone and failure-recovery surfaces.

Machine-readable diagrams are retained in:

- `reports/security/diagrams/inheritance-graph.dot`;
- `reports/security/diagrams/inheritance-printer.json`;
- `reports/security/diagrams/functions-auth-printer.json`.

The two printer runs analyzed 66 compiled contracts. The function/auth report includes dependencies,
so reviewers should filter to `src/**` contracts when preparing the final audit scope.

## Special-feature inventory

| surface | disposition | evidence / residual boundary |
|---|---|---|
| upgradeability | Protocol contracts are non-upgradeable; no replaceable proxy implementation | Arbitrum USDC remains an external upgradeable dependency |
| clone execution | EIP-1167 Clone delegates only to the immutable Factory-pinned implementation | Clone has more delegatecall/storage risk than Full; differential and activation checks are mandatory |
| arbitrary calls | No protocol-owned arbitrary target/call or arbitrary delegatecall entry point | Fixed external calls remain to USDC, Permit2, EntryPoint, Vault/Marketplace and protocol dependencies |
| destruction/origin | No `selfdestruct` or `tx.origin` in `src/**` | none identified |
| inline assembly | No project assembly in `src/**` | compiler and pinned dependencies remain in scope |
| randomness/oracle | No block randomness, VRF or price oracle | creator is the explicit result oracle; malicious creator resolution is a documented product risk |
| signatures | Permit2 witness and Paymaster EIP-712 are domain separated and bind operation-specific limits | Arbitrum Permit2 codehash, wallet interoperability, EntryPoint and KMS/HSM remain runtime dependencies |
| token callbacks | Vault inherits standard ERC-1155; Marketplace accepts only its expected single receipt and rejects batch/direct custody | arbitrary third-party custody contracts do not receive official Marketplace terminal-return protection |

The source search for `delegatecall`, `selfdestruct`, `tx.origin`, `assembly`, `ecrecover`,
`blockhash`, `prevrandao`, `random` and raw value-bearing `call{...}` found no project-owned matches
under `src/**`. The Clone's EIP-1167 delegatecall is generated by the pinned OpenZeppelin clone
runtime, not written as a project assembly block.

## Manual conclusions by attack surface

### Assets and solvency

- Principal is isolated per market Vault; fee and bond balances are separate pull-credit systems.
- Incoming primary, creation and Permit2 paths measure exact receipt or immediately enforce
  solvency, rejecting fee-on-transfer inputs.
- Outbound credits use `SafeERC20`; they deliberately trust canonical USDC transfer semantics and
  do not prove every beneficiary's balance delta.
- No administrator principal sweep was identified. Permissionless `claimFor` paths cannot redirect
  the beneficiary.
- Zero-participant timeout no longer transfers bond into an unclaimable bonus denominator; it credits
  the creator in BondEscrow.

### State transitions and ordering

- Creator resolve/void ends strictly before the timeout boundary; at the deadline only permissionless
  timeout is available, preventing creator bond-penalty evasion.
- Terminal state is written before external terminal accounting where appropriate and terminal states
  are irreversible. Asset-moving public entry points use `nonReentrant`.
- Winner, early-bird and timeout-bonus accounting uses a dynamic remaining-pool denominator. This
  preserves exact aggregate conservation; claim order/address splitting can change individual atomic
  remainder allocation and is an accepted, documented economic property.
- Official Marketplace escrow cannot be burned via holder claim/refund; a terminal listing must first
  be returned to its seller.

### Deployment and authority

- Factory starts inactive and activation is irreversible. Activation verifies dependency code,
  expected wiring and an externally reviewed address/codehash fingerprint before market creation.
- Governance can change bounded protocol defaults and protocol-level switches but cannot rewrite a
  market result or sweep user principal. Emergency authority can only pause new-risk surfaces and
  cannot stop cancellation, return, transfer or claim/refund exits.
- Full and Clone deployments remain two distinct runtime/security surfaces. The Full Vault is the
  recommended flagship mode; Clone retains its lower hard market cap and requires dedicated audit.

### Signatures and sponsored execution

- Permit2 buy/fill use canonical witness suffixes and bind chain, spender, selector, market/listing,
  outcome/amount limits, nonce and deadlines.
- Paymaster sponsorship binds both packed Paymaster gas limits in EIP-712, validates their byte-level
  header values and reserves a conservative full `maxCost` budget.
- These checks are statically and locally tested only. Real Permit2 wallet signing, Arbitrum EntryPoint
  v0.8, bundler behavior, KMS/HSM signing and multi-instance durable budget serialization are not
  runtime verified by this review.

### Indexing and off-chain recovery

- The indexer persists canonical headers for every scanned block, discovers Factory-created markets,
  walks to a common ancestor for deep reorgs and rebuilds raw/derived state atomically at the store
  boundary.
- In-memory tests cover deep reorg, dynamic discovery and projections. The independent disposable
  PostgreSQL 17.10 lane passes Paymaster 2/2, Indexer 3/3 and readiness 4/4 with zero skips. This is
  local real-database evidence, not production HA/TLS/backup/restore or Arbitrum runtime evidence.

## Security properties reviewed

- Vault assets cover outstanding principal/payout/bonus liabilities.
- Supply, principal, rake, winner pool, early-bird pool and timeout bonus conserve atomic units.
- C2C transfers do not change primary principal or outcome supply.
- Full and Clone behavior is equivalent except address, codehash, mode and deployment gas.
- Pause cannot block cancellation, terminal return, transfer, claim or refund.
- Permit2 and Paymaster authorizations cannot replay across domain, selector or bound limits.
- Factory cannot create markets before one-time dependency activation.
- Timeout principal refund does not depend on later BondEscrow settlement.

Foundry unit/flow and invariant suites provide local evidence for these properties. Coverage,
mutation, external audit and live-chain gates are reported separately and must not be inferred from
this checklist. The current coverage lane passes 20 suites and 121/121 tests; its production
`src/**` slice is line 100%, function 100% and branch 99.13%. The unfiltered raw LCOV is lower because
it also includes scripts, security harnesses and test helpers; neither slice is external-audit or
runtime evidence.

## Open release blockers

- two independent external audits, remediation reviews and bug bounty;
- whole-protocol mutation and broader authorization/state formal work;
- Echidna 0-call worker crash and the resulting failed security aggregate;
- Arbitrum Sepolia codehash/role/USDC/Permit2/EntryPoint/Paymaster end-to-end verification;
- real KMS/HSM, bundler, RPC/reorg and external-USDC-paymaster failure drills;
- API and WebSocket load lanes that previously failed their exact acceptance thresholds.

No mainnet-readiness conclusion is asserted by this report.
