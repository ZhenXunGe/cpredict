# Pinned declaration repairs

Run `npm ci --ignore-scripts`, then `npm run site:patches`. Checks/builds invoke that command explicitly; no install hook or SDK runtime patch is used. `manifests/sdk-declaration-patches.json` binds npm release URLs, lockfile integrity, original/patched declaration hashes, official evidence files, and every JavaScript/CJS/ESM/native/WASM file in each patched package (excluding its separately installed dependencies). Any version, source, runtime or unregistered patch mismatch fails before application. Reapplication is supported. An SDK upgrade requires a new review and manifest, not an automatic patch rebase.

Missing declaration dependencies are pinned as development dependencies using the upstream release manifests: MetaMask eth-sig-util 8.2.0, Solana web3.js 1.98.4 within the required `^1.98.0`, SimpleWebAuthn types 9.0.1, js-cookie types 3.0.6 and undici 7.29.1 within ofetch's 7.x line. SimpleWebAuthn 9.0.1 is deprecated but is the exact upstream type generation dependency; it adds no browser runtime import. The Wallet Standard umbrella package was removed because its additional wallet implementation exposed an unrelated declaration incompatibility; the existing base export supplies the identical account type.

Patches were generated with read-only `git diff --no-index` against original installed declaration snapshots, then applied using the official `patch-package@8.0.1` command with `--error-on-fail --error-on-warn`. Its patch creation helper performs an implicit forced installation, so that helper was not used. No `any`, ambient fake modules, `@ts-ignore` or checking exceptions are added. The repository's strict dependency gate must pass after every change. This proves declaration compatibility; actual login, signing, hosted sponsorship and device acceptance remain separate.
